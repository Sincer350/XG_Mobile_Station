Radeon RX 5700 (y otras AMD de escritorio) en ROG Ally con Windows 11
======================================================================

Esta guía es para usar una Radeon de escritorio (probada en teoría con la
RX 5700, Navi 10) en un ROG Ally Z1 Extreme a través de un adaptador XG Mobile a
PCIe, en Windows 11 con Armoury Crate SE.

## Por qué no funcionaba

Armoury Crate solo acepta los XG Mobile oficiales, así que XGMDriver se hace
pasar por uno. Para AMD solo existe un modelo oficial, la **GC32L** (RX 6850M
XT), y es el que imita el driver para cualquier Radeon.

Armoury Crate trata la GC32L de forma especial: si la base dice que va a
**PCIe Gen 4** y el equipo no es un ROG Flow X13 GV301Q, exige actualizar la
VBIOS y la BIOS para forzar Gen 3 (errores `OldVBIOS` / `UpgradingVBIOS`, ver
[Software.md](Software.md)). El XGMDriver original siempre respondía "Gen 4", así
que con cualquier AMD en el Ally la activación se quedaba atascada pidiendo una
actualización que nunca se puede aplicar a una tarjeta de escritorio.

Además, el servicio de Armoury Crate se cuelga dentro de la librería de AMD
(`amdadlx64.dll`) cuando aparece o desaparece una tarjeta gráfica. Eso provoca
el bucle de conectar y desconectar, mucho más probable con una gráfica AMD.

Esta versión de XGMDriver:

* Responde **Gen 3** para la GC32L (lo mismo que hace una GC32L oficial ya
  actualizada), así que Armoury Crate no pide actualizar la VBIOS. El ACPI del
  equipo ya pone el puerto a Gen 3 para las AMD, así que no se pierde velocidad.
* Marca por defecto el arreglo del bucle de desconexión al elegir AMD.
* Usa el formato exacto del campo `GEN` que envía una base real.

La RX 5700 funcionará a **PCIe 3.0 x4**, que es lo normal en una eGPU con el
Ally.

## Instalación

1. Actualiza Windows, la BIOS del Ally y Armoury Crate SE (MyASUS / Armoury
   Crate → Actualizaciones).
2. Descarga e instala el **driver AMD Software: Adrenalin Edition** completo
   desde amd.com (el mismo paquete sirve para la 780M del Z1E y para la
   RX 5700). **No instales** el driver de la XG Mobile GC32L que ofrece ASUS: es
   para la RX 6850M XT y no reconoce la RX 5700.
   * Si ya habías instalado otros drivers AMD, límpialos antes con
     [DDU](https://www.guru3d.com/download/display-driver-uninstaller-download/)
     en modo seguro y luego instala Adrenalin.
3. Si tenías otra versión de XGMDriver, desinstálala desde *Panel de control →
   Programas* ("Fake XGM Device") y reinicia.
4. Ejecuta `XGMDriverSetup.exe` de esta versión:
   * Elige **AMD (any Radeon, e.g. RX 5700 / 6000 / 7000)**.
   * Deja marcado **XGM disconnect loop workaround** (sale marcado al elegir AMD).
     El único coste es que desaparece el monitor de hardware de Armoury Crate.
5. Reinicia el Ally.

## Conectar la gráfica

1. Con el Ally encendido, enciende primero la fuente del adaptador y la
   RX 5700 (y conecta el monitor a la gráfica).
2. Conecta el cable XG Mobile al Ally y baja la palanca de bloqueo.
3. Acepta el aviso de Armoury Crate para cambiar a la XG Mobile.
4. Si pide reiniciar, reinicia **con todo conectado**. Después la RX 5700 debería
   aparecer en el *Administrador de dispositivos* (al principio puede salir como
   "Adaptador de pantalla básico de Microsoft"; si es así, vuelve a ejecutar el
   instalador de Adrenalin).

Para desconectar, usa siempre el icono de XG Mobile en Armoury Crate antes de
quitar el cable.

## Si algo falla

### Sigue pidiendo actualizar la VBIOS / "reiniciar ahora o más tarde"
Comprueba qué generación está viendo Armoury Crate:

```
reg query "HKLM\SOFTWARE\ASUS\eGPU"
reg query "HKLM\SOFTWARE\ASUS\ARMOURY CRATE Service\GPU Switch" /v ErrorReason
```

`DockingGen` debería ser `3` y `ErrorReason` estar vacío. Si `XGMobileModel` no
es `GC32L`, vuelve a ejecutar el instalador y elige AMD.

### Probar con Gen 4 (u otro valor) sin recompilar
El driver lee un valor opcional `PcieGen` (DWORD, 3 o 4) de la clave del
dispositivo. En PowerShell como administrador:

```powershell
$dev = Get-PnpDevice -FriendlyName "Fake XGM Device*" | Select-Object -First 1
$key = "HKLM:\SYSTEM\CurrentControlSet\Enum\$($dev.InstanceId)\Device Parameters"
Set-ItemProperty -Path $key -Name PcieGen -Value 4 -Type DWord
Disable-PnpDevice -InstanceId $dev.InstanceId -Confirm:$false
Enable-PnpDevice -InstanceId $dev.InstanceId -Confirm:$false
```

Para volver al valor por defecto (Gen 3 para AMD), borra el valor y repite las
dos últimas líneas:

```powershell
Remove-ItemProperty -Path $key -Name PcieGen
```

### Se conecta y se desconecta una y otra vez
Vuelve a ejecutar el instalador y asegúrate de que **XGM disconnect loop
workaround** está marcado. Si Armoury Crate se ha actualizado, el arreglo se
pierde y hay que volver a aplicarlo así.

### Armoury Crate dice "conectado" pero no aparece la GPU
* Reinicia con la gráfica conectada y encendida.
* En el *Administrador de dispositivos* activa *Ver → Mostrar dispositivos
  ocultos* y busca un adaptador de pantalla genérico; si está, reinstala
  Adrenalin.
* Revisa el cable y los conectores (ver la sección de problemas del
  [README](../README.md#troubleshooting)).

### Alternativa: G-Helper
[G-Helper](https://github.com/seerge/g-helper) también puede activar la XG
Mobile sin Armoury Crate. Si con Armoury Crate no hay forma, prueba a activarla
desde G-Helper con XGMDriver instalado.
